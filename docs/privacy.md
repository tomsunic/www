# Privacy policy

This website, tomsunic.com, is a personal site run by Tomislav Sunić. It is a static site
hosted on GitHub Pages. It sets no cookies of its own, runs no analytics and collects no
personal data from visitors. GitHub, as the host, may log requests as described in the
[GitHub privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Publishing tools

Videos and posts are published to YouTube and other networks with a private tool,
crosspost-studio, used only by the author. When the author signs in with Google, the tool
receives permission to upload videos to the author's own YouTube channel and to read the
channel's basic details. It stores that authorisation on the author's computer and nowhere
else. It does not access anyone else's Google account, and it shares no Google user data
with any third party.

dijeli se ni s kim.
